Review this storyboard as a strict film director and production supervisor, then return only the scenes you improve.

Check every scene, and fix only what is weak (keep scenes that already work exactly as they are):
1. **Shows the line**: with the sound off, would a viewer understand this narration line from the objects, people and text? A topic illustration is not enough; the EVENT of the line must be visible.
2. **Hero object**: is the object that carries the meaning present, big enough ("size"), in a mid or near slot, and named by "focus" or "hero": true when it matters?
3. **Purpose -> shot**: does the shot + move serve the scene's purpose (camera grammar)? Is it different from the scene before?
4. **Reveals and timing**: does the key object appear on its word ("cue") with a fitting anim? Is there a reaction beat where the line turns?
5. **Hook and ending**: is scene 1 the most striking image? Does the last scene land the one thing to remember (label with the key number/date, pull-out on the hero object)?
6. **Continuity**: same names for the same people; set and light change only for a story reason.
7. **Clutter**: remove objects that don't help the line; at most 1-2 animated objects per scene.
8. **Text**: short, exact numbers/dates/names from the narration; never invent facts that the narration doesn't say.
